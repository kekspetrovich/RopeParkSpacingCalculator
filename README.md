
# Конструктор строительной разметки

Удобный веб-инструмент для точного распределения элементов (точек, столбиков или досок) на строительных объектах, таких как платформы веревочных парков, террасы или фасады.

## Основные возможности:
- **Расчет геометрии**: Поддержка круглых платформ различного диаметра и расчет эффективного расстояния между ними.
- **Гибкие режимы расстояний**: Выбор между расчетом "По осям" элементов или "Край-Край".
- **Разнообразные типы элементов**: Разметка одиночных точек или объектов с заданной шириной (например, досок).
- **Умное распределение**: Автоматический подбор количества элементов по заданному шагу или фиксированное количество с расчетом идеальных промежутков.
- **Управление первым отступом**: 
  - Режим **MAX**: Ограничивает отступ от края, равномерно распределяя остаток.
  - Режим **Фикс**: Строго фиксирует расстояние первого элемента от края платформы.
- **Интерактивная линейка**: Визуальная шкала и список координат (последовательность разметки), которые можно скопировать одним нажатием в двух форматах (столбик или строка).
- **Экспорт и совместная работа**: Возможность поделиться ссылкой, содержащей все настройки, или сохранить схему в виде изображения PNG.

## Как пользоваться:
1. **Настройте платформу**: Выберите диаметр и общее расстояние между опорами.
2. **Выберите элементы**: Установите тип (Точка/Отрезок) и ширину, если требуется.
3. **Задайте шаг**: Укажите желаемый отступ (target gap). Приложение автоматически предложит оптимальное количество элементов.
4. **Отрегулируйте края**: Если важно расстояние от края платформы, настройте MAX 1-й отступ. Используйте переключатель "Фикс.", если отступ должен быть жестким.
5. **Используйте результат**:
   - Посмотрите на **Схему** для общего понимания.
   - Используйте **Линейку разметки** для фактического переноса размеров на деталь.
   - Нажмите на последовательность цифр, чтобы скопировать их в буфер обмена.

Инструмент создан для упрощения рутинных расчетов на стройплощадке и минимизации ошибок при разметке сложных конструкций.
